# Raw Data

Raw index-level data is obtained from the [MSCI Index Data Search](https://www-cdn.msci.com/web/msci/index-tools/end-of-day-index-data-search) for non-commercial research purposes.

Due to data licensing restrictions, the underlying MSCI data files are not included in this repository.

The required index series, data settings and relevant metadata are documented in `data/metadata/index_metadata.csv`.
